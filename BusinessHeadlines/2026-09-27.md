# Laegna–SpiReason Ecosystem — Current Usage and Historical Context
## Snapshot: 27 September 2026

This report describes the measurable public usage of the Laegna–SpiReason ecosystem from the available discrete statistics.

My notice: **these are weeks without many updates, so it's rather a base-line data except for single repo being frequently updated in last days; it cannot compete with past reports where multiple repos were always lately updated, or within the past month - but it's probably the stable interest which is always there now, showing the long-term interest rather than interaction with new information.**.

The two principal measurable surfaces are:

- `spireason.neocities.org` — broad website traffic, measured as visits, hits, views and bandwidth.
- `github.com/tambetvali/` repositories — more technical interaction, measured mainly through repository views and clones.

These statistics should **not be added together as people**. A Neocities visit is not the same measurement as a GitHub clone, and the same person can appear on several repositories or on both platforms. The totals below therefore describe **observed activity**, not a count of unique humans.

Other parts of the ecosystem — including Notaku, generated/branching Laegna sites, hosted applets and older site versions — have much less consistently collectable statistics. They are part of the ecosystem, but are not treated as if their usage were known.

# 9. The ecosystem therefore has two different traffic curves

The data is easier to understand if GitHub and Neocities are treated as different instruments.

## Website curve

The main site behaves more like a **continuous audience channel**.

Visitors arrive, browse pages, load images and follow the public presentation of the ecosystem.

Its current signal is approximately:

**146 visits/day**

with a relatively narrow weekly range around that level.

## GitHub curve

GitHub behaves more like a **collection of independent research channels**.

A repository can be quiet for weeks and then suddenly receive:

- views,
- clones,
- Google referrals,
- GitHub referrals,
- file exploration,
- updates,
- or activity caused by a newly published implementation.

Consequently, GitHub's aggregate numbers can remain active even while most individual repositories are quiet.

The ecosystem is therefore not one website with one audience curve.

It is a network of many small channels.

# 13. The meaning of "quiet" repositories

A repository with only a few views should not automatically be classified as unsuccessful.

GitHub statistics show several kinds of repositories:

### Browsing-heavy repositories

These receive many page views.

They are probably being inspected through GitHub's interface.

### Clone-heavy repositories

These receive relatively few page views but many clones.

People may be obtaining the repository directly without browsing its pages.

### View-and-clone repositories

These receive both.

They provide the clearest evidence of people both inspecting and obtaining the material.

### Archive repositories

These may receive occasional clones because somebody wants an old version.

### Infrastructure repositories

These can be used without corresponding public page browsing.

The current ecosystem contains examples of all of these.

Therefore the long tail of small numbers is not empty space. It is part of the structure of the project.

# 15. The relationship between the main site and GitHub

The two systems serve different functions.

`spireason.neocities.org` is the broad presentation and discovery surface.

GitHub is the structured technical archive and implementation surface.

A visitor can therefore encounter the project in several ways:

1. discover the main website,
2. follow a link to a repository,
3. encounter a repository through GitHub search,
4. find a mathematical or technical page through search engines,
5. clone a repository directly,
6. discover the profile and then move through its repository network.

The current statistics demonstrate why these should not be merged into one simple traffic number.

A website visitor may never use GitHub.

A GitHub cloner may never visit the main website.

A person may do both.

The ecosystem is therefore better represented as a **network of entry points** than as a single funnel.

**the update created an observable attention wave.**

The useful question is what happens after the wave:

- Does activity remain elevated?
- Do visitors return?
- Do related repositories receive increased activity?
- Does the profile receive more traffic?
- Does the main website receive referrals?
- Does the repository continue to be cloned after the update becomes old?

Those future observations would distinguish a temporary update burst from a persistent audience.

# 20. Final interpretation

The current data does not show a single giant audience suddenly appearing.

It shows something more structurally interesting:

**a distributed independent ecosystem that continues to receive measurable attention even when the publication rate slows down.**

The main website currently supplies a stable background stream of roughly 1,025 visits per week.

GitHub supplies a different form of activity: hundreds of repository clones distributed across many projects, with occasional strong bursts.

The current FrequencyCalculator peak is real, but its recent-update timing makes it better understood as an attention wave than as an established long-term baseline.

The `tambetvali` profile is numerically smaller this week, but it is the more directly leverageable signal because it is an entry point to the whole repository network.

The historical July snapshot shows that substantially larger bursts have already occurred around several theory repositories. The present lower numbers therefore fit a cyclic ecosystem in which attention moves between projects rather than a system whose every repository grows continuously.

The most meaningful current conclusion is consequently:

**Laegna–SpiReason has measurable public circulation across two fundamentally different channels — broad website discovery and focused repository interaction — and its activity is distributed across a growing network of mathematical, AI, logical, technical, artistic, spiritual and archival projects.**

The statistics do not establish the number of people who understand or use the theories, nor do they establish scientific influence. They do establish something simpler and measurable:

**the work is publicly discoverable, repeatedly accessed, cloned, explored and redistributed through several independent entry points.**

That is the observable foundation from which future growth, deeper readership, collaboration, implementation and wider recognition could occur.
